Pengaturan

Tempel URL yang muncul setelah kamu men-deploy code.gs sebagai Web App. Lihat langkah di bawah.

Cara menyambungkan ke Google Sheets

  1. Buat Google Spreadsheet baru (boleh pakai file database.xlsx yang diunduh sebagai acuan struktur kolom, lalu ganti dengan Google Sheets asli).
  2. Buka menu Extensions → Apps Script.
  3. Hapus kode bawaan, tempel seluruh isi file code.gs yang sudah diunduh.
  4. Klik Deploy → New deployment, pilih tipe Web app.
  5. Isi "Execute as": Me, dan "Who has access": Anyone.
  6. Klik Deploy, salin URL yang muncul, tempel di kolom di atas.
  7. Setiap kali kode Apps Script diubah, buat New deployment lagi agar perubahan aktif.
